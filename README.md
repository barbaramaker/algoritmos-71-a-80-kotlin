**Algoritmos 71 a 80 em Kotlin**

Este repositório contém os algoritmos de 71 a 80, originalmente escritos em Portugol e convertidos para Kotlin.

O objetivo da atividade é praticar a linguagem Kotlin e entender como aplicar operações matemáticas, variáveis, entrada e saída de dados e cálculos envolvendo porcentagens e fórmulas.

**Algoritmos desenvolvidos**

* Algoritmo 71: Calcula quantos minutos se passaram desde o início do dia.
* Algoritmo 72: Calcula o rendimento e o valor total de um depósito com juros.
* Algoritmo 73: Calcula a parte inteira, a parte fracionária e o arredondamento de um número real.
* Algoritmo 74: Calcula quantos salários mínimos uma pessoa recebe.
* Algoritmo 75: Converte o peso de uma pessoa em gramas e calcula o novo peso após um aumento de 12%.
* Algoritmo 76: Calcula o sucessor de um número entre 0 e 60, considerando que o sucessor de 60 é 0.
* Algoritmo 77: Calcula o quadrado da diferença entre dois números e a diferença de seus quadrados.
* Algoritmo 78: Calcula o número de diagonais de um polígono convexo.
* Algoritmo 79: Calcula o valor acumulado de uma aplicação mensal em uma poupança programada.
* Algoritmo 80: Calcula o faturamento anual, os ganhos com multas e a quantidade final de fitas de uma locadora.

**Comentários sobre os exercícios**

Neste bloco, consegui praticar diferentes operações matemáticas, trabalhar com números inteiros e decimais e utilizar fórmulas para resolver problemas do cotidiano.

Também aprendi a utilizar funções matemáticas como Math.pow(), floor() e roundToInt(), além de trabalhar com porcentagens, juros e conversões de valores.

Os exercícios ajudaram a compreender melhor como transformar os comandos do Portugol em Kotlin, mantendo a lógica original dos algoritmos.

**Ferramentas utilizadas**

* Kotlin
* IntelliJ IDEA
* Git e GitHub

**Organização**

Os arquivos estão organizados individualmente, de Algoritmo71.kt até Algoritmo80.kt, dentro da pasta src/main/kotlin.

Cada arquivo contém o enunciado, o código original em Portugol e sua conversão para Kotlin.
